# Контекст арены — инфраструктура lovii (санитарная справка)

> Секретов здесь нет и быть не должно: ни IP, ни кредов, ни токенов.
> Задачи аудита — в TASKS.md, материнский план — в PLAN.md.

## Стенды и код

| Стенд | Где | Что крутится |
|---|---|---|
| prod | один сервер (VPS) | core API + app + b2b + admin, docker compose |
| staging | ТОТ ЖЕ сервер | те же 4 стека, имена контейнеров с суффиксом `-staging` |
| dev | домашний мини-ПК (CHUWI, N100) | свежие копии прода, сброс = дамп+код master |
| мониторинг-хаб | CHUWI | Prometheus + Grafana + Alertmanager; прод подтянут через SSH-туннель |

4 репозитория кода: `lovii-tech/lovii-{core,app,b2b,admin}` (приватные, арене
недоступны по умолчанию — аудит идёт по артефактам, которые выдаёт координатор).
Поток: фича-ветка → staging (автодеплой) → master (прод ТОЛЬКО вручную,
`workflow_dispatch`). CI — GitHub Actions на **self-hosted раннерах**: деплой-раннеры
на прод-сервере, сборочный раннер на CHUWI. Канон безопасности CI: деплой-ключ
стирается после деплоя, SHA-пины actions, деплой проверенного DEPLOY_SHA,
`permissions: contents: read`.

## Характер проекта

Commerce-платформа с интеграцией банка (приём платежей, заявки на вывод средств,
фискализация чеков 54-ФЗ). Финансово-чувствительная: любое расширение поверхности
атаки — риск. Отсюда рамки из PLAN.md: только read-only, никаких кнопок отката,
новые компоненты не получают кредов прод-сервера.

## Существующий мониторинг (не трогаем, дообогащаем)

- Prometheus-хаб на CHUWI; экспортеры прода слушают localhost, доступ — только
  через SSH-туннель (не наружу).
- Grafana :3002, дашборд «Стенды — обзор» (cadvisor/node-exporter и пр.).
- Uptime Kuma — внешний сторож доступности (не заменяется).
- Alertmanager описан, канал уведомлений ещё не подключён (развилка владельца).

## Что планируется (кратко — детали в PLAN.md)

Без новых платформ: python-экспортеры на CHUWI (poll GitHub API read-only токеном
+ heartbeat-файлы агентов) → существующий Prometheus → новые дашборды в той же
Grafana + алерты в существующий Alertmanager. Реестр агентов — JSON-файлы,
которые ИИ-агенты пишут сами (heartbeat при работе над задачей).

## Ограничения для аудиторов

- Писать в lovii-tech/* нельзя; арена отчитывается здесь, в `reports/`.
- Приватные репо и серверы недоступны — если для вердикта нужен доступ к
  артефакту, запросите его в отчёте (координатор приложит выгрузку).
- Не предлагать новые платформы/стеки (ArgoCD, GitLab, SaaS) — рамки плана
  утверждены владельцем; предложение «вне рамок» можно дать, но отдельным
  разделом «за пределами рамок», не как вердикт NO-GO.
