# Наблюдаемость CI/CD и агентов — план, бэклог, конечная цель

> Создано 2026-10-12 по команде владельца. Статус: план готов к исполнению,
> старт — после сброса лимитов биллинга (решение владельца). Развилки помечены 🔶.
> Арена-задачи: репо `bestdeejay/lovii-arena-observability`.

## Конечная цель (Definition of Done)

Владелец открывает **один экран в существующей Grafana (:3002)** и видит без единого
SSH-захода:

1. Для каждого стенда (dev CHUWI / staging / prod, × 4 репо core/app/b2b/admin):
   текущий задеплоенный SHA, SHA источника (ветки), расхождение, время и результат
   последнего прогона CI, длительность и шаг, на котором он застрял.
2. Историю деплоев как аннотации на таймлайне (кто/что/когда залил).
3. Реестр ИИ-агентов: кто активен, над каким репо/веткой/задачей работает,
   «завис ли» (нет heartbeat > N минут при открытой задаче).
4. Алерты в существующий Alertmanager-контур: красный прогон CI, застрявший деплой,
   расхождение прод vs проверенный SHA, молчащий агент.

**Жёсткие рамки (не обсуждаются):**
- Ноль новых платформ (никаких PipeCD/ArgoCD/GitLab — деплой остаётся docker compose
  из GitHub Actions на self-hosted раннерах, канон CI_RUNNERS_SELFHOSTED.md).
- Дашборд и все новые компоненты — **только read-only**. Никаких кнопок rollback:
  откат — по-прежнему явная команда через регламент (DEPLOY_SHA, прод вручную).
- Новые компоненты не получают кредов прод-сервера: метрики идут через
  существующий SSH-туннель `mon-tunnel` и read-only GitHub-токен.
- Всё размещается на CHUWI рядом с Prometheus-хабом (не на проде).

## Архитектура (минимум движущихся частей)

```
GitHub API (gh api, read-only токен)  ─┐
Прод-сервер (version.json, git SHAs)  ─┼─► экспортеры на CHUWI ─► Prometheus ─► Grafana :3002
Heartbeat-файлы агентов (реестр)      ─┘         (poll 30–60с)        (+ существующие экспортеры)
```

- **pipeline-exporter** (python, cron/systemd timer на CHUWI): poll `gh api` по 4 репо
  → метрики `lovii_ci_run_*` (статус, длительность, conclusion, run_id) и
  `lovii_stand_sha{stand,repo,ref}` — SHA стенда из `/version.json` + git SHAs
  источника из GitHub API.
- **agents-exporter**: читает `~/LOVII/agents-registry/*.json` (heartbeat-файлы,
  см. Ф-2) → `lovii_agent{agent,repo,branch,task}` + `lovii_agent_last_seen_seconds`.
- Деплой-события → **Grafana annotations** (пишет пост-деплой шаг ci.yml простым
  curl в Grafana API через туннель — одна строка в job, канон-правка ci.yml
  через репо, не руками).
